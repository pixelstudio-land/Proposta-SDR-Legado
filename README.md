# Proposta: SDR Legado Performance

> Pixel Studio / Legado Performance  
> Máquina Comercial de IA 24/7 (AI SDR para Instagram e WhatsApp)

Este repositório contém a documentação estratégica e a Landing Page interativa da proposta de implementação da Operação Comercial com IA para a Legado Performance e produto Máquina de Orçamentos.

## Estrutura do Projeto

* index.html: Landing Page interativa com simulador de leads e gráficos.
* style.css: Design system em dark mode moderno.
* app.js: Lógica interativa da calculadora de retorno e projeção de reuniões.
* assets/: Mockups da interface do painel de controle e atendimento no Direct.
* PROPOSTA_OPERACAO_COMERCIAL_IA.md: Proposta executiva completa em primeira pessoa.

Desenvolvido por Pixel Studio.
